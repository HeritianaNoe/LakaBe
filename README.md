# LakaBe

**Fitehirizana Teknolojia Malagasy**

LakaBe dia tranokala fampahafantarana sy fizarana rindranasa (application) maimaim-poana mifototra amin'ny kolontsaina, ny fivavahana ary ny tantara malagasy. Ny tanjona dia ny mitahiry sy mampiely fitaovana nomerika izay mitazona ny votoatiny malagasy, na amin'ny finday na amin'ny ordinatera.

> *Iray ny fikasana.*

---

## Ireo rindranasa azo alaina

| Rindranasa   | Description                                                                 | Platform          |
|--------------|-----------------------------------------------------------------------------|-------------------|
| **Baiboly**  | Famakiana Baiboly isan'andro: marika miloko, naoty, fikarohana, fizarana    | Android · Windows |
| **Fanorona** | Lalao Fanorona nentim-paharazana (fisamborana amin'ny fandalovana/fisintonana) | Android · Windows |
| **Alimanaka**| Kalendrie litorjika katolika + rakitry ny Olomasina                         | Android · Windows |
| **Imerina**  | Quiz momba ny tantara Imerina (mpanjaka, daty, zava-nitranga)               | Android · Windows |
| **Fihirana** | Fitambaran'ny hira masina katolika (hira 1000+), sokajy sy fitadiavana     | Android · Windows |

### Hafa (ho an'ny ankizy – Android ihany)

- **Fanorona 5**
- **Fanorona 3**
- **Volana**

Ireo dia natao hanampiana ny ankizy hianatra ny teny malagasy sy ny kolontsaina amin'ny alalan'ny lalao.

---

## Toetra manokana amin'ny tranokala

- **Fiteny telo** : Malagasy (MG), Français (FR), English (EN) – azo ovaina amin'ny alalan'ny bokotra any ambony.
- **Endrika maoderina** : design responsive, font manokana (GangOfThree + Google Fonts), animation malefaka.
- **Navigation** : menu sticky miaraka amin'ny scroll-spy, menu hamburger amin'ny finday.
- **Fizarana maimaim-poana** : ny rakitra rehetra dia zip (APK / EXE) mba ho maivana sy azo antoka kokoa.

## Fomba fampiasana

1. Sokafy ny `index.html` amin'ny navigateur (Chrome, Firefox, Edge...).
2. Safidio ny fiteny tianao (MG / FR / EN).
3. Hijereo ny tsirairay amin'ny rindranasa ary alao ny rakitra (.apk na .exe) avy amin'ny Google Drive.

> **Fanamarihana** : Ny rakitra rehetra dia zip. Tsy misy fiatohana na fanonerana raha sendra misy olana. Maimaim-poana no zaraina.
